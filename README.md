# 📁 FileMaster Mobile

**FileMaster Mobile** adalah aplikasi toolkit pengelolaan file berbasis web yang dirancang dengan tampilan modern, ringan, dan responsif. Bisa digunakan langsung melalui browser Android maupun desktop tanpa perlu mengunduh aplikasi tambahan.

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 📂 File Manager | Memilih, mencari, dan mengelola file dalam sesi penggunaan |
| 🖼️ Image Compressor | Mengurangi ukuran gambar |
| 🔄 Image Converter | Mengubah gambar ke format JPG, PNG, dan WebP |
| 📦 ZIP & Extract | Membuat arsip ZIP dan mengekstrak file ZIP |
| 📝 Text Tools | Menghitung karakter, kata, baris, serta mengubah format teks |
| ℹ️ File Information | Melihat ukuran, tipe, dan informasi file |
| 🌙 Dark & Light Mode | Pilihan tampilan gelap dan terang |
| 📱 PWA Support | Dapat dipasang ke layar utama perangkat |

## 🔒 Privasi Pengguna

FileMaster memproses file secara lokal melalui browser pengguna. File tidak dikirim ke server aplikasi.

Pengguna tetap perlu memilih file secara manual melalui file picker. Aplikasi berbasis browser ini tidak memiliki akses bebas ke seluruh penyimpanan perangkat.

## 📥 Cara Menggunakan

1. Buka [FileMaster Mobile](https://muhzarx.github.io/FileMaster/).
2. Pilih file dari perangkat.
3. Tentukan fitur yang ingin digunakan.
4. Proses file sesuai kebutuhan.
5. Unduh hasilnya ke perangkat.

## 📲 Instalasi Android

1. Buka Live Demo melalui Google Chrome.
2. Tekan menu titik tiga.
3. Pilih **Install App** atau **Tambahkan ke layar utama**.
4. FileMaster siap digunakan seperti aplikasi biasa.
